# 甘洁教授

长江商学院副院长

 长江商学院智造创业MBA项目发起人

 金融和经济领域专家

长江商学院副院长、金融学教授、智能建造MBA项目发起人。甘洁教授拥有麻省理工学院（MIT）博士学位，曾任香港科技大学（HKUST）工商管理学院金融系教授、哥伦比亚大学（Columbia University）商学院经济与金融系助理教授，长期从事公司金融及中国资本市场的研究。2011年，甘洁教授独立获得美国学术界最高荣誉之一的Brennan 最佳论文奖，甘洁教授的一个重要研究课题是每一季度定期对工业企业进行大规模调查，基于此编制的产业经济景气指数，以及对工业经济的独特研究成果在国内外均受到普遍关注和赞赏。
