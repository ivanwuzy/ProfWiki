入口：`/ProfWiki/pku-talent-map/`。首页正文和右侧卡片均放在清华人才地图之后。院系分区、团队分组、人物卡片、公司节点、培养关系与详情跳转延续现有人才地图结构；浏览器实现复用香港地图的静态渲染方式。

2026-09-22：51 位去重人物、33 个团队 / 阅读分组、8 个院系 / 研究入口、5 家关联公司、18 条显式关系。来源为本库已有知识文章，本次没有新增外部研究或改写 raw。

先进制造与机器人学院、智能学院、计算机学院、人工智能研究院、深圳信工分别展开；跨院与联合平台单列。集成电路、科学智能及相邻交叉领域作为支撑入口，不视为全部属于具身智能。

`@` 开头的分组只帮助阅读，不断言正式实验室或行政隶属。科学智能与交叉入口中的人物保持各自真实任职资料。CoRe 行政父级未定；两个人工智能研究院 / 工学部机器人中心保持分开。平台目录关联不等于全职聘用或导师关系。历史 DeepMotion 任职及自由量级联合创业写在人物身份，未创建未经建页审核的公司节点；产业筛选目前只筛有独立公司节点的关系。

## 维护与构建

- `source/selection.cjs`：人工审阅的组织、人物、关系及原文摘录。
- `source/build.cjs`：读取所选文章，检查正式团队成员链接、关系摘录和跨院平台证据，生成 `data.js`。
- `index.html`、`style.css`、`app.js`、`data.js`：发布白名单。构建源码、维护记录不发布。
- `site/components/TalentMapLink.tsx` 与 `site/home.md`：首页入口。首页北大卡片使用官网白色校徽，与清华卡片保持 44px 徽章尺寸；地图页顶栏保留文字标识。
- `site/scripts/publish-talent-map.mjs`：网站构建后重编北大数据并复制白名单；CI 包含地图检查。

在仓库根目录执行：

```bash
node pku-talent-map/source/build.cjs
node --test pku-talent-map/source/map.test.cjs
node --check pku-talent-map/app.js
npm run build --prefix site
```

地图读取本地已审阅文章；知识库详情链接仅对 Git 跟踪文件生成，遵循网站现有发布边界。本次发布已纳入地图所需的北大知识页及原始来源，51 位人物均生成知识库详情链接。文章路径变化后应重新构建核验。
