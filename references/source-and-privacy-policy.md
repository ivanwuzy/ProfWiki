# 来源、置信度与隐私规则

本文件按需读取：当你判断证据强度、抽取人物信息、处理融资/任职/学历/奖项事实时使用。

## 来源等级

### A0：事实锚点

- 清华大学官网、清华新闻网
- 院系、研究院、实验室官网
- 个人主页、公司官网、投资机构官网
- 工商系统、专利系统、论文 DOI/出版社页、会议官网
- 奖项/竞赛官方页面

### A1：交叉验证

- 权威媒体、行业媒体
- 创投数据库：IT 桔子、企查查、天眼查、爱企查、Crunchbase、PitchBook 等
- OpenAlex、Semantic Scholar、DBLP、Google Scholar、ORCID
- GitHub、论文项目页、投资机构 Portfolio

### A2：弱线索

- 公众号、访谈、播客、社媒公开信息、二手转载
- 只能作为线索，不直接写成确定结论

## 置信度字段

```yaml
confidence:
  - verified_primary
  - verified_secondary
  - single_source
  - inferred
  - unverified
```

含义：

| 值 | 含义 |
|---|---|
| `verified_primary` | 一手来源直接支持 |
| `verified_secondary` | 权威二手来源或多源交叉验证 |
| `single_source` | 单一公开来源 |
| `inferred` | 基于公开信息推断，需要人工复核 |
| `unverified` | 未验证，不进入正式结论 |

## 必须有证据的事实

- 学历与清华关系
- 当前任职
- 创始人/核心团队身份
- 公司主营业务
- 融资金额和轮次
- 奖项/竞赛获奖记录
- 实验室/导师关系

## 编译前的证据检查

- `verified_primary` / `verified_secondary` 必须对应已实际取得并存入 `raw/` 的正文；HTTP 200、标题、导航壳、搜索摘要或只列在线链接不算完成核验。
- 逐条核对关键事实的原文位置。某来源支持任职，不代表它也支持融资、持股、创始身份或“首个/唯一”等判断；原始调研报告中的推断不能升级成官网事实。
- 中英文姓名、院系和公司必须完成身份桥接；同名、相近罗马化和机器翻译名称不能直接合并。公司创始人、中心创始主任、产品创始研发团队、顾问和发明人分开记录。
- 同一新闻稿的多个转载不算独立交叉验证。公司新闻稿/官网的能力与估值标明公司披露口径；竞赛组别不等于融资轮次，投稿不等于接收，专利申请不等于授权。
- 一份新证据仅核实部分内容时，明确写出核实范围和未决项；恢复置信度前，不把仍缺证的历史条目作为正式结论。已过日期的毕业/产品预测改为待核，不自动转成已发生事实。
- 每次身份或创业关系纠错，搜索全库姓名、别名和相关公司，同步正文、关系表及索引；原错误在修订记录中保留，避免只修单页而继续传播。

## 禁止或不建议记录

- 私人手机号、私人邮箱、住址、身份证、家庭成员
- 非公开群聊、朋友圈、内部通讯录内容
- 未授权简历全文
- 对个人动机、政治立场、健康状况等无证据推断
- 单一媒体源的融资金额直接当作确定事实

## 冲突处理

- 不要强行平均矛盾来源。
- 在相关页面写入“待验证”或“冲突与不确定性”。
- 关键冲突创建或更新 `wiki/questions/` 页面。
- 融资金额必须标注币种、公开披露口径和来源。
