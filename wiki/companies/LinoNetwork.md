## 一句话判断

Lino Network 是港科大 [陈启峰](../people/陈启峰_港科大CSE.md) 教授学术生涯早期（2017年）在硅谷发起的区块链创业项目，其联合创始人兼首席科学家身份有 Crunchbase、TechNode、港科大官方页面多方交叉印证；旗下直播应用 DLive 一度签下 YouTube 头部主播 PewDiePie 实现爆发式增长，但 2019 年底核心资产被孙宇晨（Justin Sun）旗下 TRON/BitTorrent 收购并迁移上链，创投数据库 Tracxn 已将 Lino 标注为"不再活跃"——**这是本库中少见的、创业标的已明确终止/被收购的案例**。

## 技术路线

- **自研公链**：PBFT-based DPoS（实用拜占庭容错 + 委托权益证明），Go语言实现，开源代码托管于 GitHub（`lino-network/lino`）；项目自述"并未实现全部功能，Lino Core 当时仍在开发中"。
- **核心理念**：构建"去中心化自治内容经济"（decentralized autonomous content economy），通过 LINO 代币对内容价值进行链上计量，创作者可获得打赏、礼物、订阅等多种代币化收入；并尝试点对点、拍卖式 CDN 存储视频与直播回放。
- **旗舰应用 DLive**：2018年9月在 Lino 测试网上发布的游戏直播应用，最初基于 Steem 区块链、2018年9月迁移至 Lino Network 重新上线，定位对标 Twitch/YouTube。

## 商业进展

- 2018年2月完成2000万美元代币私募融资；测试网于2018年8月上线，DLive 于同年9月发布。
- DLive 于2019年4月签约 YouTube 头部主播 PewDiePie 后迎来爆发式增长，月活由约300万增至500万以上（CoinDesk / Yahoo Finance 报道当月环比增长67%），是 Lino Network 生态最具规模的落地成果。
- 2019年底，孙宇晨（Justin Sun）旗下 TRON 子公司 BitTorrent 宣布收购/整合 DLive，DLive 随后从 Lino 自有区块链迁移至 TRON 链，代币也由 LINO 替换为 BTT；据 Coinspeaker 报道，"Lino Network 创建方 ACE Protocol Foundation"同期与 BitTorrent 达成战略合作。
- 此后未见 Lino Network 作为独立公司/区块链有新的公开经营证据；创投数据库 Tracxn 将其标注为"不再活跃"（not active）。DLive 品牌本身在被 TRON/BitTorrent 收购后仍以直播平台形式存续至近年，但已是另一控制主体下的产品，与陈启峰参与的原始 Lino Network 团队及治理关系不再相同。
