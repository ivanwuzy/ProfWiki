# 香港高校人才地图

独立地图入口：`/ProfWiki/hong-kong-talent-map/`。首页正文及右侧地图卡片均置于清华地图之后。

五校为香港大学、香港中文大学、香港科技大学、香港理工大学、香港城市大学；港科广、港中深及其关联平台通过开关加入。学校与实体独立维护，同一人物的跨校展示不重复计数。研究范围为具身智能、机器人和相关 AI，覆盖医疗、脑机、语音生成、能源材料与 AI 科学实验。

## 维护

- `source/selection.cjs`：人工选择研究团队、人物和关系；`@` 开头的分组仅为阅读分组，不代表实验室隶属。共用人物 ID；`affiliations` 保存额外校友、历史任职或联聘关系。`groupCompanyRelations` 承接院系中的学生团队创业来源，保留原文证据摘录，不补造个人创始人。
- `source/build.cjs`：读取所选 wiki 文章生成 `data.js`，检查组织成员链接、公司关系来源、培养关系的证据摘录。摘要和公开来源由文章取得；有过时摘要的条目使用人工覆盖。该过程不修改 wiki/raw。
- `index.html`、`style.css`、`app.js`、`data.js` 为发布白名单。区徽单独沿网站静态资源发布。构建资料与维护文件不发布。
- 地图数据为审阅后的快照，知识文章变化后需重新编译并核对关系，不会在浏览器中自动吸收未审阅变更。
- 人物详情只为 Git 已跟踪的文章生成知识库链接，遵循网站现有发布边界；其余实体保留摘要及公开来源。对应文章进入发布集合后重新构建即可补齐链接。

在项目根目录（已安装 `site` 依赖）运行：

```bash
node hong-kong-talent-map/source/build.cjs
node --test hong-kong-talent-map/source/map.test.cjs
```

交互：学校、方向与产业联系筛选；全局搜索；人物/公司详情；关系跳转；点击人物突出直接关系；空白处拖动、原生滚动、缩放按钮及 Ctrl+滚轮。手机默认以单校宽度阅读，可横向浏览。`/` 搜索，`Esc` 关闭；搜索结果支持上下键，地图聚焦时支持方向键与 `+` / `-` / `0`。

## 证据边界

本图收录量不是学校规模或人才排名。公司关联不等于大学控股或官方孵化；研究合作不等于雇佣或师承。王煜、刘明等历史任职另标；雅可比采用 2024 年访谈及 2025 年校方报道的创业关系，当前经营与学籍待核；段默龙显示已核副主任职务。SAIL 成员不自动绘制导师连线，邓胜亮不划入 SAIL；同名组织如两校 MMLab 分开显示。

## 2026-09-11 四校资料同步

依据本库已入库的港城大、港理工、港中深、港科广补充资料更新精选名单。地图由 68 位人物、27 家公司、45 个团队/分组增至 **86 位人物、34 家公司、66 个团队/分组**，包含 59 条人物/公司/组织关系及 11 条跨校关联；新增 18 位人物、7 家公司、21 个团队/分组。香港五校及两所内地关联高校仍独立展示，跨校人物共用 ID。

新增语音与生成 AI、能源与材料、AI 科学实验三个方向。公司入口涵盖 AI Motion Sports、Linkerbot、Sanas、智科自动化、泽康科技、翼机器人和泰康诺。后两家挂在真实组织下，产业筛选、公司计数、搜索定位和详情跳转同时支持组织来源。武执政的礼任教授及顾问身份、陈力的核心成员身份、胡君杰的共同作者关系分别标注；李文荣的讲座学科争议保留待核。
